# ProjGuard

## Safety Monitoring for Computer-Use Agents via Low-Dimensional Projections

This repository accompanies the paper **ProjGuard: Safety Monitoring for Computer-Use Agents via Low-Dimensional Projections**.

**Code availability:** The code will be published in this repository as soon as the paper is accepted. At present, this repository contains project documentation only; the implementation is not yet available here.

## Overview

Computer-use agents can interact with browsers, editors, email clients, and other applications, but malicious content encountered during a task can redirect their behavior. ProjGuard monitors the agent's accumulated response history to detect unsafe drift during execution.

The method combines a lightweight text-based monitor with selective vision-language model (VLM) intervention. The monitor computes a risk score at each step without an additional language-model call. An auxiliary VLM is invoked only when the score exceeds a calibrated threshold.

## Method

1. **Accumulate agent responses.** At step `t`, the monitored input is the sequence of responses generated by the agent from the start of the task through that step. The lightweight monitor does not receive screenshots or the accessibility tree.
2. **Vectorize the history.** Word-level feature hashing maps the accumulated response history to a fixed-dimensional sparse vector. The selected configuration uses 2,048 features.
3. **Project to one dimension.** A supervised Linear Discriminant Analysis (LDA) projection, fitted on labeled safe and unsafe trajectories, maps the vector to a scalar coordinate.
4. **Estimate risk.** The relative distances from that coordinate to the fitted safe and unsafe centroids are transformed into a scalar risk score. A calibrated threshold determines whether to raise an alert.
5. **Intervene when needed.** On an alert, an auxiliary VLM receives the task and the available multimodal execution trace, including the current observation, and proposes the next action. Without an alert, the original action is preserved.

This separates continuous, inexpensive response monitoring from the more costly multimodal reasoning used for intervention.

## Evaluation in the paper

The paper evaluates prompt-injection scenarios on **OS-Harm**, built on OSWorld, and transfer to **RiosWorld** without retraining or recalibrating the fitted monitor. It studies unsafe-trajectory rates, task completion, operational costs, representation separability, alert thresholds, and intervention-model choices.

The evaluation concerns attacks observable through agent response traces. It does not establish protection against every prompt-injection strategy or against attacks that leave little evidence in response text.
